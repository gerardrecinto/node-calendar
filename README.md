# Node Calendar

Express + MongoDB calendar app. Basic CRUD for calendar events served from a REST API, with a static HTML/CSS/JS frontend.

## Stack

| Layer | Tech |
|---|---|
| Server | Node.js, Express 4 |
| Database | MongoDB (mongoskin) |
| Frontend | Static HTML/CSS/JS |

## Running locally

Start MongoDB first, then:

```bash
npm install
node app.js
```

Open [http://localhost:3000](http://localhost:3000).
